# 玻璃雪球 · 粒子圣诞树

一棵封存在玻璃穹顶里的粒子圣诞树。体积雪在球内真实下落并响应光照，玻璃折射随视角弯曲；树、星河、爱心在粒子间丝滑变形，各形态持续自转；捏合触发满屏多簇烟花循环绽放。配乐为循环播放的《等雨停》。

单文件、零构建、无需安装任何东西。

## 在线体验

**https://jiushudemowang.github.io/glass-christmas-tree/**

## 本地运行

直接双击 `index.html` 也能看，但摄像头手势会失效。建议起一个本地服务：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000/>，点击「开启魔法」。

摄像头只用于本地手势识别，画面不会上传；拒绝授权也完全可以体验。

## 操作

| 操作 | 效果 |
|---|---|
| ✊ 握拳 / 键盘 `1` | 圣诞树 |
| 🖐 张手 / 键盘 `2` | 星河 |
| ✌️ 比耶 / 键盘 `3` | 爱心 |
| 👌 捏合 / 键盘 `4` | 满屏烟花开关（再按一次退出） |
| 挥手 / 鼠标拖拽 | 旋转视角 |
| 键盘 `M` 或底部胶囊按钮 | 音乐开关 |

形态特性：
- **银河星河**：正对相机的扁平盘 + 4 条对数螺旋臂 + 中央亮核 + 弥散晕，绕自身法线缓缓旋转，螺旋结构清晰。
- **实心爱心**：面积均匀填充的立体饱满心形，各角度 3D 摇摆都圆润不扁。
- **形态切换**：固定 2.2 秒缓入缓出；三套坐标在 shader 内各自独立旋转后再插值，过渡丝滑零跳变。
- **烟花**：满屏 11 簇、每簇 900 粒子的常驻循环系统，多处错峰齐放、持续绽放，不会一闪而过。

启动时自动播放配乐 **《等雨停》**（`dengyuting.mp3`，循环播放），带 1.2 秒渐入 / 0.5 秒渐出。可按 `M` 或点底部胶囊开关静音。

## 技术

- Three.js 0.169（WebGL，兼容性优先，非 WebGPU）
- 9000 粒子树 + 4200 体积雪粒子；GPU 顶点着色器内三套坐标各自旋转后插值实现丝滑变形与自转
- 玻璃穹顶：`transmission` + `ior 1.5` + `clearcoat` 真实折射
- UnrealBloom 后处理 + 程序化十字星芒、螺旋彩灯、许愿光点、散景
- MediaPipe Tasks Vision 手势识别（失败时自动回退到鼠标/键盘）
- HTML5 Audio 循环播放本地 MP3，渐入渐出音量控制

灵感来自 Forged.build 为保时捷做的 Holiday Snow Globe（WebGPU 体积雪），本站按其思路用 WebGL 重写。
